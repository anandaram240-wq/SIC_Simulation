Record Architecture Notes:
• Record 1: Contains instructions from 9000 to 901B (10 words = 30 bytes = 1E hex, the standard SIC max limit).
• Record 2: Contains JLT, RSUB, and 5 TABLE words (15 hex bytes). Breaks at COUNT1 RESW 1 because storage reservations generate no object code!
• Record 3: Resumes after COUNT1 for constants ZERO, ONE, and FIVE (9 bytes = 09 hex).

24-Bit Two's Complement Integer Representation in SIC

In the Simplified Instructional Computer (SIC), all standard integer words are exactly 24 bits (3 bytes = 6 hexadecimal digits). Negative values are represented using 2's complement arithmetic (2^24 - |val|).

WORD -5 Calculation
1. Magnitude (+5):
00000000 00000000 00000101
2. 1's Complement:
11111111 11111111 11111010
3. Add 1 (2's Complement):
11111111 11111111 11111011
4. In Hexadecimal (24-bit):
FFFFFB
WORD -2 Calculation
1. Magnitude (+2):
00000000 00000000 00000010
2. 1's Complement:
11111111 11111111 11111101
3. Add 1 (2's Complement):
11111111 11111111 11111110
4. In Hexadecimal (24-bit):
FFFFFE
Important Implementation Note: Python's standard string formatting format(-5, '06X') yields -00005, which produces invalid 7-character strings with a minus sign. The enhanced simulator performs format(val & 0xFFFFFF, '06X') to properly generate 24-bit SIC machine words.
